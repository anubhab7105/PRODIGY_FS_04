# Real-Time Chat Application

A real-time chat application built with Node.js and WebSocket technology that enables instant messaging between users. This is my fourth project as a Full Stack Web Development Intern at Prodigy Infotech.

## Features

- ✅ Real-time messaging using WebSockets
- ✅ User authentication (username-based)
- ✅ Online user list with count
- ✅ Message history (last 20 messages)
- ✅ Typing indicators
- ✅ System notifications for user join/leave
- ✅ Responsive design for all devices
- ✅ Auto-reconnect on connection loss

## Technologies Used

**Frontend:**
- HTML5
- CSS3
- Vanilla JavaScript

**Backend:**
- Node.js
- Express.js
- WebSocket (ws library)

**Deployment:**
- Render (or Heroku)
